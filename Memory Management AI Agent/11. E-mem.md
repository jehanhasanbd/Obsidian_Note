- **Formation (What becomes a memory?):** Unbounded input streams partitioned into discrete, uncompressed **episodic context segments** via a sliding window,.
- **Representation (How is memory represented?):** A composite tuple consisting of a high-fidelity **raw token sequence** and a lightweight **semantic summary**.
- **Storage (Where is it stored?):** Distributed across multiple **SLM-based "assistant agents"**; dormant units are stored on inexpensive disk storage,,.
- **Memory Type (What kinds of memory exist?):** Long-term **episodic memory** designed to preserve full contextual integrity and sequential dependencies,,.
- **Retrieval (How memories are retrieved?):** A **multi-pathway routing mechanism** involving global narrative alignment, latent semantic vector similarity, and symbolic entity triggers (e.g., BM25),,.
- **Ranking (How are retrieved memories prioritized?):** Candidates are ranked based on **weighted scores** across the three routing pathways to select the top-\(k\) activated chunks,.
- **Update (How does existing memory update after new context?):** **Incremental \(O(1)\) streaming updates** where tokens are appended to an active agent; once capacity is reached, a new agent is instantiated using an overlap region for continuity,.
- **Compressed (How are memories compressed/combined?):** **None**; E-mem explicitly avoids compression to prevent "destructive de-contextualization",,.
- **Forgetting (How memory forget unnecessary context?):** **None mentioned**; units simply transition to a "dormant" state on disk,.
- **Conflict (What happens when memories disagree or conflict occur?):** The master agent applies the **"Latest State Rule,"** using absolute timestamps to prioritize the most recent information over earlier states,.
- **Temporal (How is time handled?):** Managed through **overlapping sliding windows** to maintain sequence, and **absolute timestamps** attached to local evidence to resolve state transitions,,.
- **Memory Importance (How is memory importance determined?):** Determined by **query-relevance** calculated through the multi-pathway routing mechanism,.
- **Controller (Who makes memory decisions?):** A central **"Master Agent"** acts as the global planner and orchestrator of routing and aggregation,,.
- **Trigger (When does memory management happen?):** During **memory building** (context encapsulation) and at **query time** (associative activation and reconstruction),.
- **Feedback (Does future usefulness influence memory?):** **None mentioned.**
