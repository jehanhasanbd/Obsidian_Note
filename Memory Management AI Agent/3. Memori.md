Based on the **Memori** framework described in the source, here are the short answers to your questions:

- **Formation (What becomes a memory?):** Unstructured dialogue and raw interactions are distilled into **semantic triples** and **summaries**.
- **Representation (How is memory represented?):** A dual-layered structure of **semantic triples** (subject–predicate–object) and **conversation summaries**.
- **Storage (Where is it stored?):** Stored in **Memori Cloud** (managed storage) and indexed locally using **FAISS** for fast similarity search.
- **Memory Type (What kinds of memory exist?):** Granular **semantic triples** (static facts/preferences) and cohesive **conversation summaries** (narrative/temporal context).
- **Retrieval (How memories are retrieved?):** Via a **hybrid search approach** combining cosine similarity over embeddings with BM25 keyword matching.
- **Ranking (How are retrieved memories prioritized?):** Using **Intelligent Ranking** and **Decay** factors within the recall engine.
- **Update (How does existing memory update after new context?):** The **Advanced Augmentation pipeline** incrementally distills new raw interactions into updated semantic assets.
- **Compressed (How are memories compressed/combined?):** Dialogue is compressed into **compact triples** and **concise summaries**, acting as an efficient compression layer.
- **Forgetting (How memory forget unnecessary context?):** Acts as a **cognitive filter** that removes noise (pleasantries/tangents) during extraction and uses **Decay** in the recall engine.
- **Conflict (What happens when memories disagree or conflict occur?):** The system is instructed to **prioritize the most recent memory** based on its timestamp.
- **Temporal (How is time handled?):** Handled through **timestamped** memories and summaries; the agent calculates actual dates from relative time references (e.g., "last year").
- **Memory Importance (How is memory importance determined?):** By scanning for **high-signal information** like facts, preferences, and constraints while filtering out low-signal "noise".
- **Controller (Who makes memory decisions?):** The **Advanced Augmentation pipeline** (for distillation) and the **Memori SDK** (for intercepting and managing requests).
- **Trigger (When does memory management happen?):** Occurs as a **background pipeline** triggered when the SDK intercepts conversation logs.
- **Feedback (Does future usefulness influence memory?):** **None**.
- **Cost (How expensive is management?):** Highly efficient, using an average of **1,294 tokens per query**.
